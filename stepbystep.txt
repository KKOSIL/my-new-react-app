챕터 1: 프로젝트 설정 및 컴포넌트 기초 다지기

단계 1: 프로젝트 폴더 생성 및 이동
목표: React 프로젝트를 위한 최상위 디렉토리 생성.
핵심: mkdir, cd 기본 터미널 명령어.
단계 2: React 앱 생성
목표: create-react-app으로 React 프로젝트 초기 구조 자동 생성.
핵심: npx create-react-app [프로젝트명], npm start (개발 서버 실행).
단계 3: VS Code에서 프로젝트 열기 & 기본 코드 정리
목표: VS Code에서 프로젝트 폴더를 열고, create-react-app의 불필요한 초기 파일 및 코드를 제거하여 클린 상태 만들기.
핵심: src 폴더 구조 이해, App.js와 index.js의 역할, 파일 삭제 및 import 문 정리.
단계 4: 첫 React 컴포넌트 만들기 (Sidebar.js)
목표: 좌측 사이드바를 담당할 Sidebar.js 컴포넌트 파일 생성 및 기본 구조 작성.
핵심: import React from 'react';, 함수형 컴포넌트 구조 (function ComponentName() { return <JSX />; }), export default ComponentName; (컴포넌트 내보내기), import ComponentName from './path'; (컴포넌트 가져오기), React 컴포넌트 이름 규칙 (대문자로 시작).
단계 5: 두 번째 React 컴포넌트 만들기 (MainContent.js)
목표: 우측 메인 콘텐츠 영역을 담당할 MainContent.js 컴포넌트 생성 및 App.js에 연결.
핵심: 컴포넌트 분리의 이유 (책임 분리, 재사용성), App.js에서 여러 자식 컴포넌트 배치.
단계 6: 기본 레이아웃 CSS 스타일링
목표: App.css, Sidebar.css, MainContent.css에 기본 스타일을 적용하여 사이드바와 메인 콘텐츠를 나란히 배치.
핵심: display: flex; (Flexbox 기본), width, margin-left를 이용한 컴포넌트 배치, position: fixed; (사이드바 고정).
챕터 2: 데이터 관리 및 목록 렌더링 (State & Props)

단계 7: 앱 상태 정의 (App.js의 tasks)
목표: 앱 전체의 핵심 데이터인 tasks (작업 목록)를 App.js에서 useState 훅으로 관리.
핵심: useState 훅 사용법 (const [state변수, setState함수] = useState(초기값);), 배열과 객체를 초기값으로 사용하는 방법, 각 작업 객체의 속성 (id, title, status)의 의미.
단계 8: App.js에서 MainContent로 데이터 전달
목표: App.js의 tasks 상태를 MainContent 컴포넌트로 props를 통해 전달.
핵심: props (<Component propName={propValue} />)를 이용한 부모-자식 데이터 전달, {} 중괄호의 의미 (JSX 내 JS 변수 사용).
단계 9: TaskColumn 컴포넌트 생성 및 데이터 준비
목표: 각 작업 상태(칼럼)를 표시할 TaskColumn.js 컴포넌트 생성, MainContent.js에서 각 칼럼에 맞는 작업 데이터를 필터링.
핵심: Array.prototype.filter() 메서드 (조건에 맞는 요소만 걸러 새 배열 반환, 엑셀 필터와 유사), 화살표 함수 (element => condition) (간결한 콜백 함수 정의), task (개별 요소) vs tasks (전체 배열).
단계 10: MainContent에서 TaskColumn 렌더링
목표: MainContent.js에서 필터링된 tasks를 바탕으로 여러 개의 TaskColumn 컴포넌트를 렌더링.
핵심: Array.prototype.map() 메서드 (배열의 각 요소를 변형하여 새 배열 반환, JSX 목록 렌더링에 필수), key prop의 중요성 (key={item.id} - React가 목록 요소를 식별하는 고유 값).
단계 11: TaskColumn 디자인 디테일 조정
목표: TaskColumn.css에 각 칼럼 및 작업 아이템의 디자인을 샘플 이미지와 유사하게 적용.
핵심: border-bottom (테두리), box-shadow (그림자), transform: translateY() (위치 이동), :hover (마우스 오버 효과), transition (부드러운 애니메이션), CSS 선택자 (.class1.class2, div > div).
동적 클래스 적용: TaskColumn.js에서 columnClass = columnTitle.toLowerCase().replace(/\s/g, '-');를 통해 동적으로 클래스 이름 생성, className={base ${dynamicClass}} (템플릿 리터럴).
챕터 3: 작업 추가 기능 구현

단계 12: AddTaskForm 컴포넌트 생성 및 배치
목표: 새로운 작업을 입력할 input 필드를 포함하는 AddTaskForm.js 컴포넌트 생성, TaskColumn.js 하단에 배치.
핵심: UI와 로직 분리 (폼 UI만 먼저 구성).
단계 13: AddTaskForm 입력 필드 상태 관리
목표: input 필드에 입력되는 값을 AddTaskForm 컴포넌트의 상태로 실시간 관리.
핵심: useState로 newTaskTitle 상태 선언, input의 value={newTaskTitle} (상태와 입력 값 동기화), onChange={(e) => setNewTaskTitle(e.target.value)} (입력 변경 감지 및 상태 업데이트).
단계 14: App.js에 addTask 함수 정의
목표: App.js 내부에 새로운 작업을 tasks 상태에 추가하는 addTask 함수 구현.
핵심: 고유 id 생성 로직 (Math.max와 스프레드 문법 ...), setTasks(prevTasks => [...prevTasks, newTask]) (불변성을 지키는 상태 업데이트), addTask 함수의 매개변수 (title, status)의 의미.
단계 15: addTask 함수 전달 (Props Drilling)
목표: App.js의 addTask 함수를 onAddTask props 이름으로 App → MainContent → TaskColumn → AddTaskForm 순서로 전달.
핵심: 함수를 props로 전달하는 방법 (onAddTask={addTask}), on 접두사 관례 (이벤트 핸들러), props 드릴링 개념.
columnId 전달: TaskColumn에서 AddTaskForm에게 columnId={columnTitle} props를 전달하여, AddTaskForm이 자신이 속한 칼럼의 status를 알 수 있도록 함.
단계 16: AddTaskForm에서 새 작업 추가 로직 실행
목표: input 필드에서 Enter 키를 눌렀을 때, onAddTask 함수를 호출하여 새 작업을 추가하고 입력 필드 초기화.
핵심: onKeyDown 이벤트 핸들러, e.key === 'Enter' (키 감지), newTaskTitle.trim() !== '' (빈 값 방지), e.preventDefault() (기본 동작 방지), onAddTask(newTaskTitle.trim(), columnId) (전달받은 함수 호출 및 필요한 인자 전달), setNewTaskTitle('') (입력 필드 초기화).
